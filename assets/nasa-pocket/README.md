# NASA Artemis pocket set

Four short clips are downloaded from the official [NASA Artemis Audio Library](https://www.nasa.gov/artemisaudio/). NASA describes the library as free to download and cleared for use under its media-usage guidelines; use must not imply NASA endorsement.

The sampler never plays these automatically. **S → ADD NASA POCKET SET** explicitly copies them into the current browser’s local IndexedDB library, where they can be auditioned, mapped to pinch and deleted. Source and credit stay attached to each clip.
